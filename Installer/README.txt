NanaZip Custom
==============

Base: NanaZip 6.5.1800.0 estável
Origem: https://github.com/M2Team/NanaZip
Personalização: https://github.com/DigitalfoxPT/NanaZip

INSTALAÇÃO

1. Extraia todos os ficheiros deste pacote para a mesma pasta.
2. Execute Install.cmd.
3. Aceite o pedido de Controlo de Conta de Utilizador.
4. O instalador adiciona o certificado público a Pessoas Fidedignas e instala o MSIXBundle.

O pacote possui uma identidade própria e pode coexistir com o NanaZip oficial.
Caso mantenha ambos instalados, poderão aparecer duas entradas NanaZip no menu de contexto.

DESINSTALAÇÃO

Execute Uninstall.cmd para remover a aplicação e o certificado instalado por este pacote.

NOTA SOBRE A ASSINATURA

Este pacote utiliza um certificado autoassinado criado durante a compilação no GitHub Actions.
O certificado privado não é publicado nem incluído no instalador.
